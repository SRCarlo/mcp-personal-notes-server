# MCP Personal Notes Server

A beginner-friendly Model Context Protocol (MCP) server that allows AI applications to manage personal notes.

## Features

- Save notes
- List notes
- Get a note
- Search notes
- Delete notes
- MCP-compatible tools
- Streamable HTTP transport

## Tech Stack

- Node.js
- JavaScript
- Express
- Model Context Protocol
- Zod
